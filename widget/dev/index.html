Sprint 2 Phase B moved widget delivery + auth into the Node.js proxy at ../proxy/. To verify the widget end-to-end, start the proxy and visit it directly — the proxy ships its own dev landing page that script-tags the bundle. 

cd ../proxy
npm install
export PROXY_SESSION_SECRET="$(openssl rand -hex 32)"
export DEMO_SYNAPCORES_TOKEN="<a JWT from your SynapCores /v1/auth/login>"
cp projects.example.json projects.json
npm start

# then open
open http://127.0.0.1:5060/

See proxy/README.md for the full setup (config schema, CORS, SameSite for production, security checklist).

If you only want to iterate on widget code without spinning up the proxy, run npm run dev in this directory and the build watcher rebuilds dist/widget.js on every save. The proxy hot-serves the new bytes on the next page load.
