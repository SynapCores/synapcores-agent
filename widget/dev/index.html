Sprint 1 MVP

@synapcores/widget — MVP

The widget is in the bottom-right. This page demonstrates a fully configured Sprint 1 install. Compared to the Sprint 0 spike you should see: a purple primary color, animated typing dots, dark mode that follows your system preference, markdown rendering in agent replies, ESC-to-close, focus trap, a "Reconnecting…" banner if the backend drops, and a full-screen overlay if you shrink to phone width.

What's new vs Sprint 0

  • Theming: data-primary-color, data-position, data-theme
  • Auto dark/light via prefers-color-scheme + reactive media query
  • Mobile: full-screen overlay below 480px (resize your window to see it)
  • Animated 3-dot "thinking" indicator
  • Markdown rendering (bold / italic / inline code / fenced code blocks / links)
  • Exponential-backoff WS reconnect (1s, 2s, 4s, 8s, 16s, cap 30s)
  • "Reconnecting…" status banner
  • ARIA role="dialog", focus trap, ESC closes
  • prefers-reduced-motion respected (no dot pulse, no panel slide)

Verify against the mock backend

# terminal 1
.venv/bin/python widget/dev/mock_backend.py

# terminal 2
cd widget && npm run dev

Then visit http://localhost:5050/. Click the chat button, send a message, watch the dots pulse, and see the (mock) You said: … reply. Try **bold**, *italic*, and a fenced ```code block``` in the input to confirm the input is treated as plain text (only agent replies parse markdown).
