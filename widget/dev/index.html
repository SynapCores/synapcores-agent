Sprint 0 dev

@synapcores/widget — spike

This page is a fresh static HTML host that script-tags the freshly-built widget. If the floating chat button shows up bottom-right, opens a panel, and an end-to-end turn → reply round-trip works against the v1 backend at ws://localhost:8810/ws, Sprint 0 is done.

Run the v1 backend first

cd ../../  # repo root
python -m synapcores_agent.web   # serves at http://localhost:8810

Then build the widget and open this page

cd widget
npm install      # one-time
npm run build    # writes dist/widget.js
npm run dev      # rebuild on change + serve this page at :5050

Visit http://localhost:5050/ and click the chat button. The first message should arrive after one Brain loop cycle (recall → RAG → route → generate). Open DevTools → Network → WS to watch the wire frames.

The script tag below is the entire install. data-backend is the WebSocket URL. Everything else is optional and overrides defaults.
