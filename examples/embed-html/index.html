Acme support — embedded chat widget

The floating chat button bottom-right is delivered from the jsDelivr CDN; sessions + WS proxy through your @synapcores/widget-proxy. The browser holds only an HttpOnly cookie; all SynapCores credentials live server-side.

Recommended — CDN delivery + SRI pinning

Public CDN, version-pinned, tamper-proof:

<script defer
  src="https://cdn.jsdelivr.net/npm/@synapcores/widget@0.4.0/dist/widget.js"
  integrity="sha384-rn44GdC0gnzNPwhJYHl4TEzahTnCGWtcE/N7QJZ1T5L+Sta8Bh/2d4lga2FaM4NB"
  crossorigin="anonymous"
  data-api-base="https://chat.your.com"
  data-project-key="pk_abc123"></script>

Alternative — proxy-hosted (no CDN dep)

If you'd rather not depend on an external CDN, your proxy already serves the same bundle at /widget.js:

<script defer
  src="https://chat.your.com/widget.js"
  data-api-base="https://chat.your.com"
  data-project-key="pk_abc123"></script>
